# Assistant — downloads

Private, on-device meeting notes, tasks and journal for Windows.

**[Download the latest version →](https://github.com/vrittech/assistant-releases/releases/latest)**

Get `Assistant_x.y.z_x64-setup.exe` from the latest release and run it. It installs for your user only (no admin rights needed), and keeps itself up to date.

> Windows may say "Windows protected your PC" because the installer isn't code-signed yet. Click **More info → Run anyway**.

This repository only hosts installers and update files. Source code is private.
